# ARCANUM Content Visual

Parte de un brief y copy aprobados. Si están en `ready_for_review`, detente en
preview; solo `approved` habilita el render final.

## Formatos

- Post o carrusel: 1080×1350.
- Story: 1080×1920.
- Una idea principal por tarjeta.
- Texto y marca se renderizan de forma determinista, nunca dentro de una imagen
  generada por IA.

## Dirección visual

- Old money oscuro: burgundy, navy y dorado mate.
- Composición editorial asimétrica; evitar plantilla genérica de IA.
- Prioriza grabados históricos con licencia comprobada o imágenes generadas para
  la pieza.
- No uses símbolos esotéricos como decoración si contradicen el tema.

## Flujo

1. Confirma copy, formato, número de tarjetas y CTA.
2. Selecciona o genera el recurso visual y registra su procedencia.
3. Produce una especificación por tarjeta: texto, jerarquía, fondo y foco.
4. Renderiza preview y comprueba contraste, márgenes y lectura móvil.
5. Escribe `alt_text` después de ver el asset final.
6. Entrega archivos y manifiesto; no publiques.

## Gate

Rechaza assets sin licencia, texto cortado, tipografía diminuta, marca deformada,
claims nuevos o un `alt_text` escrito antes de existir la imagen.
