# Checkpoint - ARCANUM - 2026-08-21

## Resumen

Se audito el candidato Android y se fijo API 36 como requisito explicito de compilacion. Backend y Flutter estan verdes. El release firmado sigue bloqueado por configuracion externa ausente, no por codigo.

- Gate release Android: `5 passed`.

- Configurar `ADMOB_APP_ID`, `ADMOB_REWARDED_ANDROID`, `ADMOB_INTERSTITIAL_ANDROID` y public SDK key de RevenueCat.
- Incrementar `versionCode` si Play Console ya recibio el codigo 2.
- Construir AAB release firmado, verificar firma/manifest/hash e instalar desde prueba interna.
- Completar ficha y declaraciones; iniciar prueba cerrada con 12 testers durante 14 dias.
- Posponer features nuevas hasta tener telemetria de beta. El bloqueo actual es distribucion, no falta de modulos.
