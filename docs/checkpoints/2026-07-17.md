# Checkpoint — ARCANUM — 2026-07-17

## Resumen

Se cerró una etapa amplia de rendimiento, seguridad de cuenta y preparación para Google Play. La app reduce trabajo visual y de red en Hoy, Cielos, Oráculo y Materia Arcana; además incorpora borrado integral de cuenta y una configuración Android segura para futuros builds firmados.

Relacionado: [[MOC-ARCANUM]], [[Checkpoint-2026-07-15-2]], [[ARCANUM-PlayStore-Plan-Migracion-2026-07-15]].

## Cambios realizados

- Se optimizaron Hoy, Cielos y Oráculo para reducir animaciones permanentes, reconstrucciones y cargas repetidas.
- La API añadió cachés y consultas más compactas para datos astrales, Materia Arcana y contexto del Oráculo.
- Materia Arcana recibió nuevas identidades visuales para aceites, inciensos y resinas, con manifiesto y generadores reproducibles.
- El arranque autenticado usa el perfil local seguro y valida la sesión en segundo plano, sin bloquear la primera pantalla por Railway.
- El grimorio conserva AES-256-GCM, compatibilidad de lectura legacy y aislamiento entre cuentas.
- Se implementó `DELETE /users/me`, cascadas de base de datos, invalidación de caché y limpieza local de tokens, perfil, onboarding y clave del grimorio.
- Ajustes ahora permite cerrar sesión y eliminar cuenta con confirmación escrita `ELIMINAR`.
- Android usa el package final `com.arcanum.magick` y movió `MainActivity` a la ruta correspondiente.
- Los builds release ya no usan la firma debug. Sin `key.properties` y upload keystore, Gradle rechaza el AAB con un error explícito.
- Se añadió `android/key.properties.example`; claves, contraseñas y keystores quedan ignorados por Git.
- Gradle eliminó el toolchain duplicado AGP 8.1/Kotlin 2.0, los mirrors Aliyun y dependencias AndroidX no usadas.
- La memoria del daemon bajó de 8 GB a 2 GB para estabilizar la compilación en Windows.
- La identidad pública dejó atrás textos de plantilla en Android, `pubspec.yaml` y la PWA.

## Estado actual

- Suite Flutter: 44 pruebas aprobadas.
- `flutter analyze`: cero problemas.
- Suite backend unitaria: 32 pruebas aprobadas en la validación anterior de esta etapa.

## Decisiones y notas

- `com.arcanum.magick` queda como identificador candidato final. Se vuelve irreversible al publicar la primera versión en Play Store.
- Ningún correo personal se publicará por defecto. El contacto legal permanece bloqueado hasta crear un canal real.
- Un build release sin firma debe fallar. No se permite fallback silencioso a la clave debug.
- Context7 confirmó que `android.newDsl=false` y `android.builtInKotlin=false` son la compatibilidad temporal documentada para plugins aún no migrados.
